# 侧边栏 (Sidebar) 设计规范

## 概述

本文档定义 EasyProduct Admin 管理系统中侧边栏菜单的设计规范，包括收缩/展开状态、悬浮展开模式和视觉样式。

## 1. 侧边栏结构

### 1.1 两种状态

#### 收缩状态 (图标栏)

```
┌────┐
│ 🏠 │  <- 首页图标 (64px宽)
├────┤
│ 📦 │  <- 商品管理
├────┤
│ 🛒 │  <- 订单管理
├────┤
│ 👥 │  <- 用户管理
├────┤
│ ⚙️ │  <- 系统设置
├────┤
│ ◀  │  <- 展开/收起按钮
└────┘
```

#### 展开状态 (完整菜单)

```
┌────────────────────┐
│ 🏠 首页            │
├────────────────────┤
│ 📦 商品管理        │
├────────────────────┤
│ 🛒 订单管理        │
├────────────────────┤
│ 👥 用户管理        │
├────────────────────┤
│ ⚙️ 系统设置        │
├────────────────────┤
│ ◀ 收起             │
└────────────────────┘
```

### 1.2 悬浮展开模式

```
收缩状态              悬浮展开
┌────┐ ┌────────────────────┐
│ 🏠 │ │ 🏠 首页            │
├────┤ ├────────────────────┤
│ 📦 │◀│ 📦 商品管理 ▼      │
├────┤ │ ├─ 商品列表        │
│ 🛒 │ │ ├─ 分类管理        │
├────┤ │ └─ 品牌管理        │
│    │ └────────────────────┘
```

## 2. 视觉规范

### 2.1 尺寸规格

| 属性 | 收缩状态 | 展开状态 |
|------|----------|----------|
| 宽度 | 64px | 220px |
| 高度 | 100vh | 100vh |
| 菜单项高度 | 48px | 48px |
| 图标区域 | 64x48px | 48x48px |
| 过渡时间 | 300ms | 300ms |

### 2.2 颜色规范

| 菜单项悬停 | #263445 | 悬停背景 |

#### 文字与图标

| 状态 | 图标色 | 文字色 |
|------|--------|--------|
| 默认 | #BFCBD9 | #BFCBD9 |
| 悬停 | #FFFFFF | #FFFFFF |
| 激活 | #409EFF | #409EFF |

```
┌────────────────────┐
```

## 3. 交互规范

### 3.1 展开/收起

| 操作 | 行为 |
|------|------|
| 点击展开按钮 | 侧边栏从 64px 展开到 220px |
| 点击收起按钮 | 侧边栏从 220px 收起为 64px |
| 点击外部 | 悬浮面板关闭 |

### 3.2 悬浮展开

收缩状态下：
- 鼠标悬停在菜单项上
- 延迟 200ms 后显示悬浮面板
- 面板显示子菜单或完整菜单项

```
延迟时间: 200ms
过渡动画: 300ms ease-out
面板背景: #304156
阴影: 0 4px 12px rgba(0,0,0,0.15)
```

### 3.3 Tooltip 提示

收缩状态下，鼠标悬停显示菜单名称：

```
    ┌─────────────┐
┌───┤  商品管理   │
│ 📦│             │
└───┴─────────────┘
```

- **位置**: 右侧居中
- **背景**: #303133
- **文字**: #FFFFFF, 12px
- **延迟**: 500ms
- **过渡**: 200ms

## 4. 动画规范

### 4.1 侧边栏展开/收起

```css
.sidebar {
  transition: width 300ms cubic-bezier(0.4, 0, 0.2, 1);
}

.sidebar.collapsed {
  width: 64px;
}

.sidebar.expanded {
  width: 220px;
}
```

### 4.2 子菜单展开/收起

```css
.submenu {
  transition: 
    height 300ms ease-in-out,
    opacity 250ms ease-in-out;
}
```

### 4.3 图标旋转动画

```css
.arrow-icon {
  transition: transform 300ms ease;
}

.arrow-icon.expanded {
  transform: rotate(180deg);
}
```

## 5. 功能实现

### 5.1 状态管理

```typescript
// sidebarStore.ts
interface SidebarState {
  collapsed: boolean;
  activeMenu: string;
  openMenus: string[]; // 展开的子菜单
}
```

### 5.2 菜单数据结构

```typescript
interface MenuItem {
  id: string;
  title: string; // i18n key
  icon: string;
  path?: string;
  children?: MenuItem[];
  hidden?: boolean;
}
```

### 5.3 路由集成

- 菜单与 Vue Router 路由配置关联
- 支持动态菜单（根据权限）
- 支持外链菜单

## 6. 响应式适配

| 断点 | 行为 |
|------|------|
| ≥1200px | 默认展开，可收起 |
| 992px-1200px | 默认收起，支持展开 |
| <992px | 隐藏，通过汉堡菜单触发 |

### 6.1 移动端适配

```
移动端抽屉菜单
┌─────────────────────────────────┐
│ ☰  EasyProduct                  │
├─────────────────────────────────┤
│                                 │
│  ┌───────────────────────┐     │
│  │ 🏠 首页               │     │
│  ├───────────────────────┤     │
│  │ 📦 商品管理          │     │
│  │   ├─ 商品列表       │     │
│  │   └─ 分类管理       │     │
│  └───────────────────────┘     │
│                                 │
└─────────────────────────────────┘
```

- 从左侧滑入
- 遮罩层点击关闭
- 手势滑动支持

## 7. 可访问性

- 支持键盘导航
- ARIA 属性标记
- 焦点状态可见
- 屏幕阅读器支持

## 8. 性能优化

- 菜单状态持久化 (localStorage)
- 虚拟滚动（大量菜单项）
- 懒加载子菜单
