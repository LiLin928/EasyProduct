# 页签 (Tab) 设计规范

## 概述

本文档定义 EasyProduct Admin 管理系统中多页签组件的设计规范，包括视觉样式、交互行为和实现要求。

## 1. 页签位置与结构

### 1.1 页签下沉模式

- **位置**: 页签独立于 Header，位于 Header 下方
- **高度**: 40px
- **背景**: 白色 (#FFFFFF) 或浅灰色 (#F5F7FA)
- **分隔线**: 1px solid #E4E7ED

```
┌─────────────────────────────────────────────────────────┐
│  Header (Logo + 用户信息)                                │
├─────────────────────────────────────────────────────────┤
│  [页签栏 - 40px高度]                                     │
│  [首页] [商品管理] [订单管理] [+]                       │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  内容区域                                                │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

### 1.2 胶囊式页签样式

```
┌────────────────────────────────────────────────────────┐
│                                                        │
│   ┌────┐  ┌────┐  ┌────┐                              │
│   │首页│  │商品│  │订单│  [+]                        │
│   └────┘  └────┘  └────┘                              │
│   ↑                                     ↑             │
│   │                                     │             │
│   激活状态                              新建页签        │
│   - 背景: #409EFF                       图标按钮        │
│   - 文字: #FFFFFF                                     │
│   - 圆角: 8px                                         │
│                                                        │
└────────────────────────────────────────────────────────┘
```

## 2. 页签视觉规范

### 2.1 尺寸与间距

| 属性 | 值 | 说明 |
|------|-----|------|
| 页签高度 | 32px | 统一高度 |
| 圆角 | 8px | 胶囊式圆角 |
| 页签间距 | 4px | 页签之间间距 |
| 内边距 | 8px 16px | 水平内边距 16px，垂直 8px |
| 图标尺寸 | 14px | 页签图标 |
| 关闭按钮 | 14px | 右侧关闭图标 |

### 2.2 颜色规范

| 状态 | 背景色 | 文字色 | 图标色 |
|------|--------|--------|--------|
| 默认 | transparent | #606266 | #909399 |
| 悬停 | #F5F7FA | #409EFF | #409EFF |
| 激活 | #409EFF | #FFFFFF | #FFFFFF |
| 关闭按钮悬停 | #F56C6C | #FFFFFF | - |

### 2.3 字体规范

- **字体大小**: 14px
- **字重**: 400 (正常), 500 (激活)
- **字体**: 系统默认字体

## 3. 交互规范

### 3.1 基础交互

| 操作 | 行为 |
|------|------|
| 点击页签 | 切换到该页签，内容区域显示对应页面 |
| 悬停页签 | 背景色变化，显示关闭按钮（如果有） |
| 点击关闭 | 关闭当前页签，自动切换到左侧页签 |
| 点击新建 (+) | 打开快捷菜单，选择要打开的页面 |
| 拖拽页签 | 支持页签顺序拖拽调整 |

### 3.2 右键菜单

页签支持右键菜单，包含以下操作：

```
┌────────────────────┐
│  刷新              │
│  关闭              │
│  关闭其他          │
│  关闭所有          │
├────────────────────┤
│  在新窗口打开      │
└────────────────────┘
```

### 3.3 过渡动画

- **切换动画**: 250ms ease-in-out
- **悬停效果**: 150ms ease
- **关闭动画**: 200ms ease-out

## 4. 功能规范

### 4.1 页签状态管理

使用 Pinia Store 管理页签状态：

```typescript
// tabsStore.ts
interface TabState {
  tabs: TabItem[];
  activeTab: string;
}

interface TabItem {
  id: string;
  title: string; // i18n key
  path: string;
  icon?: string;
  closable: boolean;
  cached: boolean; // 是否缓存
}
```

### 4.2 路由同步

- 页签与 Vue Router 同步
- URL 变化时自动激活对应页签
- 支持浏览器前进/后退

### 4.3 页签持久化

- 刷新页面后恢复页签状态
- 存储在 localStorage 或 sessionStorage

### 4.4 多语言支持

- 页签标题使用 i18n key
- 显示时通过 `$t('key')` 翻译
- 禁止硬编码中文

## 5. 特殊情况处理

### 5.1 页签过多

- 超过容器宽度时显示滚动箭头
- 支持鼠标滚轮横向滚动
- 显示 "..." 快捷菜单访问隐藏页签

### 5.2 未保存提示

- 关闭页签前检查是否有未保存内容
- 显示确认对话框
- 支持 "保存并关闭"、"不保存关闭"、"取消"

## 6. 响应式适配

| 断点 | 行为 |
|------|------|
| ≥1200px | 正常显示所有页签 |
| 992px-1200px | 适当缩小页签宽度 |
| <992px | 显示滚动箭头，支持滑动 |

## 7. 可访问性

- 支持键盘导航 (Tab, Arrow keys)
- 支持屏幕阅读器
- 高对比度模式兼容
- 键盘快捷键：Ctrl+Tab 切换页签

## 8. 参考实现

基于 Element Plus 的 ElTabs 组件进行封装，自定义样式以符合本规范。
